# Business Contact Book

A simple dark-themed React contact manager inspired by the dashboard screenshot.

## Features
- Dashboard cards for total contacts, companies, VIP contacts and categories
- Add, edit and delete contacts
- Save name, job title, company, email, phone number, address and category
- Search contacts and filter by category
- Export contacts to a CSV file
- Responsive layout for desktop and mobile

## Run in VS Code

1. Extract `Business-Contact-Book.zip`.
2. Open the extracted `business-contact-book` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run these commands:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

**Note:** This starter version keeps contacts in React memory while the page is open. Refreshing the page resets the sample data. A database or browser storage can be added later.
